# The Null

An experimental Minecraft Fabric mod adding The Null, a dark cave dimension
focused on exploration, progression, and environmental mechanics.

## Current Version

v0.0.1 — Early Alpha

Currently being developed for Minecraft Java Edition 26.3 using Fabric.

## Status

Very early development. Expect major changes, bugs, broken worlds, and
unfinished content.

## Building

Build instructions will be added once the initial Fabric project is working.
